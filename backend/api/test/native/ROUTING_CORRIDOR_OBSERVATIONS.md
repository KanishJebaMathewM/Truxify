# Native Route/corridor observation contract

Run `NODE_ENV=production LOG_LEVEL=fatal node --test backend/api/test/native/corridorService.node.mjs` with Node24/Axios1.20.0/Pino10.3.1. Actual Axios, repository CircuitBreaker, native abort signals and private loopback HTTP are used. No public OSRM, database/Supabase, hardware or vehicle controls are involved.

[OSRM Route](https://project-osrm.org/docs/v5.24.0/api/#route-service) success uses `code: Ok`, ordered routes and requested GeoJSON geometry. Admission requires complete finite geographic LineString coordinates (2–20000points), finite nonnegative distance/duration at most1e12metres/seconds and a decoded response at most1MiB. Only the first recommended route is used. NoRoute is a successful observed provider outcome with unobserved straight-line fallback; malformed payloads, HTTP errors, size failures and timeouts count as breaker failures. Native reset20seconds/request timeout are configured through the actual constructor and Axios receives the breaker signal.

Origin/destination and radius are admitted/owned before awaiting HTTP. Radius is finite0–pi*EarthRadius; explicit zero remains zero, while omitted/null uses the configured25000metre default. Constructor timeout is an integer1–60000milliseconds. Existing rounded route-distance/duration presentation and zero-distance/time fallback are retained. New routeSource/routeObserved/routeReason fields distinguish an observed road route from unobserved straight-line fallback. Caller mutation cannot rewrite published origin/destination or arrays.

Envelopes retain the existing ordered boundingBox keys. Latitude expands by spherical angular radius and clamps at the poles. Longitude expands using the widest vertex latitude and spherical-circle bound; dateline wrapping or pole coverage returns a conservative[-180,180]global longitude interval. Outward six-decimal rounding protects boundary vertices. The native spherical destination oracle samples every5degree bearing at eight centres and five radii. This is a conservative spherical envelope of vertex bounds, not an exact PostGIS buffer, road polygon or ellipsoidal survey. Broad intervals can produce extra query candidates, and the current database query limit may reduce completeness. SpatialMatcher/query semantics are unchanged.

Fallback remains available to existing consumers and is explicitly unobserved; this does not make DriverDispatchPipeline inspect provenance or prove safe live dispatch. Actual native profitability compatibility is tested, but full dispatch/database/provider startup is excluded. Other pending GPS/filter/geofence/quote fixes remain independent.

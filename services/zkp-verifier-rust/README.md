# 🔐 Truxify Rust Zero-Knowledge Proof (ZKP) Verifier Microservice

This directory contains the **Rust Zero-Knowledge Proof (ZKP) Verifier Engine** for high-security, privacy-preserving verification of driver identity, proof-of-funds, and location geofence compliance without exposing underlying PII data.

---

## 🔒 Security & Performance Features

- **Rust Memory Safety**: Zero data races and guaranteed memory safety for sensitive cryptographic verification circuits.
- **Microsecond Proof Verification**: Evaluates Ed25519 proof signatures in sub-millisecond execution times.
- **Privacy-Preserving KYC**: Validates driver rating, license status, and wallet solvency without revealing actual identity or account balances.
- **Unforgeable Proofs**: Proofs are Ed25519 signatures over the canonical public statement. The verifier ships **only the public verification key** — it is impossible for a client that reads this binary to forge a valid proof, because signatures can only be produced by the prover's private key.

## 🔑 Configuring the Verification Key

The verifier reads the Ed25519 public key from the `TRUXIFY_ZKP_VERIFYING_PUBLIC_KEY` environment variable (32-byte hex). A dev-only default is compiled in so the service runs out of the box, but **production deployments must set this variable** and provision the matching private key to the proving service out of band — the private key must never be shipped inside the verifier.

```bash
# e.g. a keypair generated by `openssl genpkey -algorithm ED25519`
export TRUXIFY_ZKP_VERIFYING_PUBLIC_KEY=03a107bff3ce10be1d70dd18e74bc09967e4d6309ba50d5f1ddc8664125531b8
```

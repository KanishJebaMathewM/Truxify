# Owned native PINN checkpoint tuple

New saves retain model_state_dict and optimizer_state_dict and add scheduler_state_dict plus pinn_config version 1. Configuration records native geometry/activation, equation family and data/physics loss weights. Receiving objective configuration must match; per-invocation PDE coefficients and observation provenance are not inferred from weights. Existing two-key files remain accepted as model/Adam only: the receiving scheduler policy is retained, its history explicitly reset, and its last learning rate bound to the loaded optimizer. This is not historical scheduler resumption. Old readers ignore new fields and retain their previous unchecked behavior.

Complete source keys, geometry and finite state are admitted before native dtype casts; postcast model/moments are checked again. Ordinary ordered single-group native Adam requires coherent scalar policy, positive epsilon, complete initialized moments, matching shapes/dtype/device, nonnegative variances, integral scalar float steps and AMSGrad maxima. Custom group metadata, reordered/multiple groups, fused/capturable/differentiable/decoupled Adam modes reject. Native float32/64 CPU and CUDA targets are supported; CUDA execution is untested.

The complete native ReduceLROnPlateau state requires valid mode/sentinel, factor, threshold, epsilon, minimum rates, integral history/counters, cooldown/patience coherence and last rates matching the paired optimizer. The untouched initial best sentinel is permitted; completed native history requires a finite best metric. Source scheduler policy and history restore together. Private actual model/Adam/scheduler preparation precedes live publication.

Publication retains model, parameter, optimizer, scheduler and buffer identities. An ordinary publication exception directly restores old registered values, native group/state contents, scheduler attributes, prior gradients and mixed modes. Valid incoming tuples can repair corrupt prior numeric state. Successful load retains existing modes/gradients; it does not restore RNG, earlier observations, shuffle state or a whole-epoch receipt. Moment/gradient alias identities are not guaranteed.

Public training, prediction and checkpoint operations share one process-local reentrant lock. Actual source integration with existing #17820 preserves its native checked training/worker/cancellation ownership and equations under the same lock. Direct external model/optimizer/scheduler readers/writers and custom hooks are outside this fence. Native trainer copies receive independent locks while maintaining their own scheduler-to-optimizer binding.

Admission policies allow up to 8,000,000 registered values and 24,000,000 moment values. These do not bound all allocation, file deserialization or time. Private native model/moment snapshots increase memory use. Storage serialization may still leave an incomplete file on failure; crash-atomic file replacement is outside this change. No asynchronous cancellation/fatal-device/cross-process/RNG/whole-epoch/custom-topology recovery, path-security/signed artifact, calibrated PDE/vehicle/physical quality, production provider/sensor/hardware or future numerical stability guarantee.
